# Render 무료 플랜 콜드 스타트와 서비스 URL 접미사

**문제 1**: 배포된 챗봇의 첫 응답이 30초~1분 걸림.

**원인**: Render 무료 플랜은 **15분 미사용 시 컨테이너가 슬립**되고, 다음 요청이 오면 그때 다시 깨어남(콜드 스타트).

**해결**: 서버 측에서 할 수 있는 건 없고 UX로 대응 — 챗봇 위젯 로딩 문구에 "서버가 잠들어 있었다면 깨우는 데 30초~1분 걸릴 수 있어요"를 표시. `/health` 엔드포인트를 만들어 두면 슬립 여부 확인에도 유용하다.

---

**문제 2**: 배포 후 `https://<서비스명>.onrender.com`으로 접속하니 404.

**원인**: Render가 최근에는 서비스명 뒤에 **랜덤 접미사**를 붙임 (예: `knowledgebase-backend-an48.onrender.com`). 서비스명만으로 URL을 추측하면 틀린다.

**해결**: 대시보드의 서비스 페이지 상단에 표시되는 실제 URL을 복사해서 쓸 것. 프론트엔드 코드에 하드코딩하기 전에 `/health`로 먼저 확인.
